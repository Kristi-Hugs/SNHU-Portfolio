Artemis Financial Security Assessment (CS-305)
Project Overview

Artemis Financial is a financial services company that required improvements to its software security infrastructure to better protect sensitive customer information. The goal of this project was to identify vulnerabilities, implement secure communication protocols, and reduce security risks within the application.

Key Accomplishments

Analyzed software security vulnerabilities
Implemented HTTPS and secure communication practices
Generated and reviewed dependency security reports
Assessed and mitigated software risks
Applied secure coding principles
Validated application functionality after security enhancements
Reflection

One of the most valuable lessons from this project was learning how software security directly impacts business operations, customer trust, and data protection. I gained hands-on experience using security scanning tools, evaluating vulnerabilities, and determining appropriate mitigation strategies.

After implementing security improvements, I tested the application and reviewed updated vulnerability reports to ensure the software remained functional while reducing security risks. This project strengthened my understanding of secure software development and reinforced the importance of building security into every stage of the development lifecycle.
